# Sprites de Hormiga para AntMaze Net-Race

Para personalizar las imágenes de la hormiga según su orientación, coloca en este directorio las siguientes imágenes en formato PNG transparente (tamaño sugerido: 64x64 px o 128x128 px):

- `ant_up.png` (Hormiga mirando hacia arriba)
- `ant_down.png` (Hormiga mirando hacia abajo)
- `ant_left.png` (Hormiga mirando hacia la izquierda)
- `ant_right.png` (Hormiga mirando hacia la derecha)

Si las imágenes no existen en esta carpeta, el juego usará automáticamente un renderizado procedimental fluido dibujado directamente en el Canvas HTML5.
